流光日程 · 玻璃拟态版使用说明
===================

双击“流光日程.exe”即可运行，不需要安装任何软件。它与原版使用不同文件夹和数据文件，可以并排运行；如需沿用原版日程，请在关闭两个程序后自行备份并复制 tasks.json。

当前版本为 3.0 原生版，不会启动或驻留 PowerShell 进程。完整新版说明见 V3-使用指南.md。

升级使用：先关闭正在运行的旧版，再打开同目录的“流光日程-v3.0.exe”。当前 tasks.json 可继续读取；首次保存前自动建立历史恢复点。

3.0 新增：确认人和跟进日期、实际执行与最终完成时间、撤销/重做、回收站、自动备份和恢复、计划与截止日期分离、跨日安排、高级重复规则、中文快速批量录入、保存筛选、子清单、关联资料、响应式周计划、专注计时、桌面胶囊。

快速添加按 Ctrl+N；全局可用 Ctrl+Alt+N。列表“更多视图”和右下角“工具与视图”可打开全部功能。编辑文本时 Ctrl+Z 保留文本撤销；其他位置 Ctrl+Z/Ctrl+Y 撤销和重做任务操作。

任务卡片、数量、今日角标、视图切换、下拉菜单、弹窗、确认反馈和错误提示均有动态反馈。视图标签选中底片会滑动；玻璃浓度滑杆拖动时即时预览，数值轻微浮入。关闭 Windows 系统动画后会直接显示最终状态。

右上角齿轮可以切换浅色/深色模式。主题色提供预设色、色相/饱和度明度调色盘（拖动时实时预览）以及系统调色盘；也可输入 #RRGGBB。玻璃底色浓度滑杆按 1% 步进，拖动时即时预览。窗口使用 WPF 透明圆角与半透明渐变，不实时模糊后方的其他程序。单击任务卡片可查看完整详情。

时间控件与日期框同高，只显示当前数值。滚轮、单击或方向键可调整，右键可反向调整；小时显示“全天”时不设时间。分钟默认按 15 分钟调整，按住 Shift 可逐分钟调整；已有任务的任意分钟会原样保留。

本版针对高分屏优化：100% 缩放使用清晰的字形排版，125% 及以上使用高分辨率字形；内容区、卡片、输入框和弹层使用不透明底色以重新启用 ClearType，并开启布局像素对齐。程序按每显示器 DPI 感知，在 1080p、2K、4K 以及 125%/150%/200% 缩放下保持字体和细线清晰。若字体仍发虚，请先在 Windows 设置中确认显示缩放和 ClearType 调优。

使用方法：
1. 点击“新建”添加日程，可设置计划/截止日期、跨日范围、时间、分类、重复、提醒、地点、备注、项目、标签、优先级、子清单和关联资料。
2. 日程页按日期和跟进紧迫度分组显示任务；“今天”、“待确认”和“已完成”可快速筛选。
3. 月历页选择日期查看当天安排，单击日程查看详情，再点“编辑日程”修改。
4. 顶部搜索框可搜索标题、地点、备注、项目、标签和审核人。
5. 点击日程查看详情，可在同一行选择“待完成 / 待确认 / 已完成”。待确认日程集中在独立视图，不计入已完成；审核通过后再选已完成，重复日程此时才会建立下一次安排。
6. 设置了时间与提醒的日程，会在应用运行时显示 Windows 通知；重新打开时会补报过去 24 小时内的漏提醒。应用关闭期间不会准时通知，也不会写入 Windows 计划任务。
7. 拖动顶部可移动窗口；拖动窗口边缘可调整大小。
8. 右上角菱形按钮可切换“始终置顶”。
9. 日程、窗口位置、大小和置顶状态会自动保存。

文件说明：
- 流光日程.exe / 流光日程-v3.0.exe：正式版程序，平时只需要运行流光日程.exe
- tasks.json：任务、跟进、子清单、重复规则及回收站，请勿删除
- widget-settings.json：窗口位置、大小、置顶状态与外观设置
- planner-settings.json：保存的筛选
- backups/：历史恢复点
- 流光日程-错误日志.txt：仅在程序发生错误时自动生成
- DesktopTodo.cs / Planning.cs / Workspace.cs / PlanningChecks.cs / Motion.cs：原生程序源码
- UI.xaml：界面和控件样式
- DESIGN.md / PRODUCT.md / V3-使用指南.md：设计、产品与新版使用说明
- app.manifest：Windows 程序清单
- 桌面日程.ico：应用图标
- Build-Exe.ps1：一键重新编译脚本
- Publish.ps1：编译并生成 dist 发布目录、便携 ZIP 和 SHA256SUMS.txt

如果想让它开机自动出现：
按 Win + R，输入 shell:startup，然后把“流光日程.exe”的快捷方式放进打开的文件夹。
