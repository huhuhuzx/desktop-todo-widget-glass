# 流光日程 · 玻璃拟态版

这是 [桌面待办清单](https://github.com/huhuhuzx/desktop-todo-widget) 旁边的独立外观版本，保留待办、日程、月历与提醒功能。界面按玻璃拟态风格重做：柔光、半透明分层、细边框、轻颗粒与清晰的文字层级；浅色、深色和自选主题色均可用。窗口仍采用单一 WPF 透明圆角，不调用 DWM Acrylic，也不实时模糊窗口后方的其他应用。

## 编译

在 Windows 11 上使用 Windows PowerShell 运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\Build-Exe.ps1
```

编译脚本使用系统的 .NET Framework WPF 编译器，生成 `流光日程.exe`。它与原版可以并排运行，任务和本机设置分别保存在本文件夹的 `tasks.json` 与 `widget-settings.json` 中；新文件夹不会自动复制原版的个人数据。若任务文件损坏，程序会停止启动并保留原文件，不会把空列表写回去。

时间使用与日期框同高的单值控件：滚动鼠标滚轮、单击或按方向键调整小时与分钟，右键可反向调整；小时显示“全天”时不设时间。日期弹窗提供月份／年份切换和“回到今天”。提醒仅在程序运行时准时触发；重新打开程序时，会补报过去 24 小时内仍未提示的日程。程序完全关闭期间不会弹出通知，也不会创建 Windows 计划任务。

在外观设置中点击主题色卡片，可直接选择预设色，或输入 `#RRGGBB` 应用任意颜色。主题色同步用于操作按钮、选中／悬停状态、提醒角标、滑杆及玻璃层的轻微色调。透明度滑杆会即时预览材质变化，数值在不延迟读数的前提下轻微浮入；视图选中底片平移，主题色区域展开和收起有短暂过渡。

界面动效按 transitions-dev 的数字变化、标签滑动和展开/收起用途改写为原生 WPF 动画；数字和滑杆拇指只使用位移、缩放与透明度，不对文字施加逐帧模糊。关闭 Windows 系统动画后，界面会直接切换到最终状态。运行 `流光日程.exe --preview` 可在 `preview` 文件夹重新生成浅色首页、深色设置页和紧凑窗口预览图。预览使用内存中的演示日程，不读取或改写真实 `tasks.json`。

## 隐私

仓库仅包含源码、界面定义、图标、清单及编译脚本。个人任务数据 `tasks.json`、本机设置 `widget-settings.json` 和编译产物均不纳入版本控制。发布或分享时请勿手动上传这些本地文件。
