# 流光日程 · 玻璃拟态版

这是 [桌面待办清单](https://github.com/huhuhuzx/desktop-todo-widget) 的独立外观版本，保留待办、日程、月历与提醒功能。界面按玻璃拟态风格重做：柔光、半透明分层、细边框、轻颗粒与清晰的文字层级；浅色、深色和自选主题色均可用。

## 下载

前往 [Releases](https://github.com/huhuhuzx/desktop-todo-widget-glass/releases) 下载最新版本，双击即可运行。

## 功能

**3.0 版使用方法见 [V3-使用指南.md](V3-使用指南.md)。** 新版增加确认跟进、撤销与回收站、自动备份和恢复、计划与截止分离、高级重复、快速批量录入、保存筛选、子清单、关联资料、响应式周计划、专注计时与桌面胶囊。

- 日程、今天、月历、待确认、已完成五种视图
- 工具中另有周计划、到期、逾期、收集箱、专注、回收站和数据恢复入口
- 在日程详情中选择「待确认」后，日程会移入独立的待确认视图；审核通过前不计入已完成，也不会提前生成下一次重复日程。停止原日程提醒，并按设置的跟进日期提醒
- 月历标记有日程的日期，列表直接显示备注摘要
- 日程列表采用像素级滚动；滚动时显示细滚动条，停止后淡出，下方仍有内容时会显示滚动提示
- 自定义标题、日期、时间、分类、重复、提醒、地点与备注
- 玻璃拟态界面：半透明分层、柔光、细边框与轻颗粒
- 浅色 / 深色模式，主题色可自由选择
- 玻璃底色浓度可调
- 适配 1080p / 2K / 4K 与 125% / 150% / 200% 缩放；内容区、卡片与弹层使用不透明底重新启用 ClearType，文字和细线更清晰
- 任务提醒与漏提醒补报
- 窗口可拖动、缩放，并支持始终置顶
- 数据保存在本地，不上传任何服务器

## 快速开始

1. 下载并运行程序
2. 点击右上角「新建」添加日程
3. 在设置中调整主题色、外观与玻璃浓度
4. 点击日程查看详情，在同一行选择「待完成／待确认／已完成」；待确认日程集中在独立视图，审核通过后再标记已完成

任务数据保存在程序目录下的 `tasks.json`，本机设置保存在 `widget-settings.json`，保存筛选位于 `planner-settings.json`，历史恢复点在 `backups/`。更新时先关闭旧版，再运行同目录下的新版。本版本与原版使用不同文件夹，可并排运行。

## 从源码编译

在 Windows PowerShell 中运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\Build-Exe.ps1
```

编译需要系统自带的 .NET Framework WPF 工具链，会生成 `流光日程.exe`。生成发布目录、便携 ZIP 与 SHA256 校验文件可运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\Publish.ps1
```

`Publish.ps1` 只打包 EXE、`V3-使用指南.md`、`使用说明.txt` 和 `SHA256SUMS.txt`，不会包含个人任务、本机设置或 `backups/`。

## 设计说明

设计取舍与材质限制见 [DESIGN.md](DESIGN.md)。窗口外壳采用单一 WPF 透明圆角与半透明渐变，不调用 DWM Acrylic，也不实时模糊窗口后方的其他应用；内容区与弹层使用不透明底色以保留 ClearType 文字清晰度。高分屏适配方式见 [V3-使用指南.md](V3-使用指南.md#清晰度与高分屏)。

## 隐私

本项目完全在本地运行，不会联网上传数据。仓库仅包含源码与编译脚本，个人任务数据与本机设置不会纳入版本控制。
